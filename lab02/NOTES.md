# Local Git States

# Рабочая папка (working directory)
Папка на компьютере, где находятся реальные файлы проекта, которые можно редактировать, открывать и удалять.

# Индекс (staging area)
Промежуточная зона между working directory и историей коммитов в репозитории. Служит для подготовки файлов к коммиту.

# Коммит (commit)
Команда, которая сохраняет текущее состояние файлов в staging area в виде постоянного узла в истории проекта.




# Различия между Git и GitHub
Git - это локальный инструмент контроля версий.
GitHub - это веб-сервис для совместной работы и хранения Git-репозиториев.




# Использованные команды

# git status
Команда, которая отображает текущее состояние working directory и staging area, показывая, какие файлы изменены, подготовлены к коммиту или еще не отслеживаются Git.

# git diff
Команда, показывающая только свежие изменения, которые уже написаны в файлах, но еще не подготовлены к коммиту. При выполнения git add команда становится пустой.

# git diff --staged
Команда, которая показывает то, что войдет в будущий коммит, если выполнить git commit.




# Ветки
Ветка — это имя, прикрепленное к последней сохраненной версии проекта. 
Задача ветки — изолировать изменения для безопасного написания кода, не нарушая стабильность рабочей версии проекта и работы других людей.
При новом коммите программа записывает снимок изменений и запоминает, от какого предыдущего шага они были сделаны. Имя ветки сдвигается вперед.
Слияние переносит проверенный результат из изолированной ветки в общую историю проекта.
